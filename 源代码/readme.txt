一、项目简介
本项目是一个基于 C++ 与 Qt 框架 开发的图形化四则运算测试系统，面向小学生设计，具备题目生成、计时答题、自动判分、答卷保存与历史回顾等功能。

二、运行环境要求
1. 操作系统
Windows 10/11

或支持 Qt 的 Linux / macOS 系统

2. 开发与运行依赖
Qt 版本：5.15 或以上

编译器：

Windows：MinGW 或 MSVC

Linux：g++

macOS：clang++

C++ 标准： C++17 或以上

3. 第三方库
本项目仅使用 Qt 官方模块，无需额外安装第三方库。

三、功能说明
1. 用户管理
支持普通用户与管理员登录

管理员可生成题库，普通用户仅可答题

2. 题目生成
随机生成 20~100 道 四则运算题目

支持加减乘除与括号混合运算

题目保存至 questionbank.txt

3. 答题与计时
系统自动计时，实时显示答题时间

用户逐行输入答案，提交后自动判分

4. 答卷保存与评价
答题记录保存至 records.txt

系统根据历史成绩给出个性化评价

5. 表达式计算
支持表达式合法性校验

使用 中缀转后缀 + 栈结构 实现计算

四、操作流程
1. 登录系统
输入用户名和密码（初始用户见下文）

管理员账号：admin，密码：admin123

普通用户账号：student1，密码：123456

2. 生成题库（管理员功能）
点击“生成题库”按钮

系统自动生成题目并保存至文件

3. 开始答题
点击“开始答题”按钮

题目显示在左侧文本框，右侧输入答案（每行一题）

4. 提交答卷
点击“提交答卷”按钮

系统自动判分，显示得分、用时与评价

5. 查看历史记录
记录自动保存，下次登录时可查看历史成绩与评价

五、输入输出格式
1. 题目格式
示例：(3+5)*2-4

每题以 = 结尾，后接正确答案，保存于 questionbank.txt

2. 答案输入格式
每行一个整数答案

示例：

text
12  
8  
5  
3. 记录文件格式（records.txt）
text
用户名 时间 得分 总题数  
示例：admin 2025-01-05 14:30:00 18 20  
六、文件结构
text
源代码.rar 解压后结构：
├── bin/                # 可执行文件（编译后生成）
├── obj/                # 编译中间文件（可删除）
├── moc/                # Qt 元对象编译文件
├── widget.ui           # 界面文件
├── widget.pro          # Qt 项目文件
├── main.cpp            # 程序入口
├── widget.h/cpp        # 主窗口类
├── user.h/cpp          # 用户管理类
├── calculate.h/cpp     # 表达式计算类
├── questionbank.h/cpp  # 题库生成类
├── record.h/cpp        # 答题记录类
├── questionbank.txt    # 题库文件（运行后生成）
├── records.txt         # 记录文件（运行后生成）
├── users.txt           # 用户文件（运行后生成）
└── readme.txt          # 本文件
七、编译与运行
1. 使用 Qt Creator 打开项目
打开 widget.pro

选择编译器（如 MinGW）

点击“构建”并运行

2. 命令行编译（示例）
bash
qmake widget.pro
make
./bin/widget.exe  # Windows
./bin/widget      # Linux/macOS
3. 直接运行可执行文件
进入 bin/ 目录，双击 widget.exe（Windows）或执行 ./widget（Linux/macOS）

八、注意事项
首次运行会自动创建 users.txt，包含初始用户信息

请勿手动删除运行中生成的 .txt 文件

答题时请确保答案格式正确（每行一个整数）

如需重新生成题库，请以管理员身份登录操作
